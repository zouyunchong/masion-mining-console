# MASION 当前电脑挖矿助手

CPU 挖矿控制台与本机助手：默认 RandomX（rx/0），通过 unMineable 按 LTC 结算。支持启停、线程配置、实时算力与日志、只读收益同步、配对管理、清除数据和卸载。当前版本没有显卡挖矿、自动提现或卖币功能。

## 从源码运行

此仓库只包含源码、脚本和第三方来源/校验说明，不包含个人配置、登录密码、矿池 API 凭证、录屏、Node/XMRig 二进制或完整安装包。

1. 安装 Node.js 22 或更新版本。项目只使用 Node 内置模块，无需安装 npm 依赖。
2. 从 `VENDOR-SHA256.json` 中对应平台的官方地址下载 XMRig 6.26.0，核对 SHA-256。将二进制放入 `bin/xmrig`（Mac，需可执行权限）或 `bin/xmrig.exe`（Windows）；也可通过 `XMRIG_PATH` 指定路径。
3. 执行 `npm run build:uninstall`，生成助手下载卸载文件所需的 ZIP。此命令只创建压缩包，不执行卸载。
4. 执行 `npm start`，打开 http://127.0.0.1:4780/。若安装版助手已使用该端口，应使用现有助手，或在隔离的开发环境运行源码。
5. 用本机配对码连接线上网页。首次运行助手不会自动挖矿；启动矿工前请核对、填写自己的矿池账户别名。

`PORT` 可修改本机调试端口，`ASSISTANT_DATA_DIR` 可指定独立数据目录。线上网页固定连接当前电脑的 4780 端口，不连接其他调试端口。不要共享 `.local/` 或让助手监听公网。

安装脚本针对带运行环境的发行包：制作安装包还需按 `VENDOR-SHA256.json` 准备对应平台的 Node.js，将可执行文件放入 `runtime/node` 或 `runtime/node.exe`，并保留 Node 官方许可证。源码开发使用 `npm start`，不需要运行安装脚本。

## 校验和网页构建

```sh
npm test
npm run build
npm run build:uninstall
```

`npm test` 使用临时目录、隔离端口和模拟矿工，不会启动、停止或清除已安装的真实矿工。`smoke.mjs` 是明确启用后才运行的真实矿工测试，会实际启停矿工，不应在正在使用的助手上自动执行。

`npm run build` 将静态控制台输出到 `dist/`，默认部署路径 `/LTC/`，可用 `BASE_PATH` 改变静态基础路径。助手默认只允许 `https://masion.xyz` 跨域访问；更换域名时需同时调整 `device-auth.mjs` 的 `SITE_ORIGIN` 和 `public/app.js` 的线上来源判断，再验证配对。上线步骤见 `PUBLIC-DEPLOYMENT.md`。

## 使用发行包

在任何支持的电脑打开 https://masion.xyz/LTC，网页只连接这台电脑的 127.0.0.1:4780 助手。没有安装助手或没有配对时，不能启动矿工，也不会回退去控制其他电脑。

## 首次使用

1. 网页下载对应助手：Mac Apple 芯片、Mac Intel，或 Windows x64。压缩包内含 Node.js 22.23.3 和 XMRig 6.26.0，不需要另外安装 Node。
2. 解压，Mac 双击顶层 `启动挖矿助手.command`，Windows 双击顶层 `启动挖矿助手.cmd`。安装过程不需要管理员权限；助手会在登录系统后运行，但矿工不会自动启动。
3. 打开 http://127.0.0.1:4780/，查看本机配对码。
4. 回到 https://masion.xyz/LTC，输入配对码，点击「配对当前电脑」。浏览器若询问本地网络访问权限，需要自行允许；推荐最新 Chrome 或 Edge。若浏览器阻止 HTTPS 页面访问本地助手，请通过网页「检查助手连接」排查权限；本机助手仍可用于停止矿工。
5. 核对页面显示的当前设备名称，再点击「启动矿工」。默认最多 4 线程（少于 4 核的设备相应降低），只挖这一台。

配对码 10 分钟有效，一次使用后更换。配对令牌绑定本机助手；换电脑需要重新安装、配对。浏览器保存本机的令牌，但不保存矿池密码或 unMineable API Secret。同一电脑另一浏览器需另行配对。包内不包含现有设备的配置、地址、密码、API 密钥或配对令牌。

## 每次使用

安装后的助手后台运行。在这台电脑上打开同一个网址即可查看、启动、停止矿工。关闭网页不会停止挖矿；关闭助手、休眠或关机会停止/暂停该设备挖矿。取消浏览器配对不会停止矿工，可通过本机助手停止。

安装目录：

- Mac：`~/Library/Application Support/MasionMiningHelper`，用户 LaunchAgent 为 `xyz.masion.mining-helper`。
- Windows：`%LOCALAPPDATA%\MasionMiningHelper`，登录启动入口在用户 Startup 文件夹中。

本机页面只负责设备状态、复制配对码、进入线上控制台、停止矿工和配对维护；算力、收益、矿池配置、日志统一在线上网页。已连接的网页会收起安装说明。更换配对码不会解除已配对浏览器，撤销所有配对不会停止已运行矿工。

也可不安装，解压后直接运行 `start.command`（Mac）或 `start-windows.cmd`（Windows），保持终端运行。

## 矿池与收益

默认账户别名 Masion-LTC，矿工名按本机名称生成，每台设备独立。需要使用自己的 unMineable 账户时，停止矿工后在网页修改矿池用户名。默认矿池 `rx.unmineable.com:443`，TLS，算法 rx/0，密码 x，XMRig 开发者捐赠 1%。

算力与 accepted/rejected 来自本机 XMRig HTTP API。LTC 金额需要在该设备的账户连接区填入只读 API 凭证，来自官方 `/v1/assets/LTC/stats`。显示未提现挖矿所得、账户总余额和累计已支付，不把份额直接换算为币。账户金额可能包含多台矿工；不是当前设备独立收益。没有自动提现或卖出操作。

## 安全与实现

助手仅绑定 127.0.0.1。域名只托管网页和下载包，不代理到任何固定 Mac。HTTPS 页面请求明确的本机地址，浏览器的本地网络权限仍由用户决定。

只允许 https://masion.xyz 的跨域请求，必须先用本机短期配对码获取随机设备令牌；所有状态和控制请求必须携带该令牌。修改操作仍需会话 token。其他来源无 CORS 许可；配对码不能被线上页面直接读取；错误配对码有频率限制。API 使用固定 XMRig 路径和 JSON 配置，不接受任意命令。矿工 API 使用 restricted 模式与随机令牌，不外露配置或凭证。

设备状态和 `.local/` 配置只在本机。Mac 上目录 700、敏感文件 600；Windows 文件继承当前用户安装目录权限。配置文件按运行需求以明文保存在本机，勿共享 `.local/`。Windows 停止进程使用操作系统终止；Mac 先 SIGINT 再超时强制退出。IPC 守护进程在助手异常退出时清理矿工。

## 验证与限制

`npm test` 验证配置、奖励字段、HMAC、配对、设备隔离和暴力猜码限制。`TEST_REAL_MINER=1 node smoke.mjs` 在助手运行、矿工停止时执行真实启动/重启/停止测试。

已在当前 Mac 实机验证。Windows 和 Intel Mac 安装包的官方二进制校验和、文件结构及平台代码已检查；当前环境没有 Windows 或 Intel Mac 实机，不能声称完成实机测试。Windows x64 包不适用于 Windows ARM。

Node 与 XMRig 来自官方发行版，SHA-256 记录在 VENDOR-SHA256.json。浏览器本地网络权限说明：https://developer.chrome.com/blog/local-network-access

## 矿池连接修复

针对本机网络对 `rx.unmineable.com` 返回异常地址的情况，助手为此矿池使用 Google DNS 的 HTTPS 解析，通过仅监听回环地址、仅允许该矿池目标的临时 SOCKS 通道连接正确地址。XMRig 到矿池的 TLS 保持端到端开启；不会安装 VPN、Cloudflare、修改系统 DNS 或改变系统代理。每次矿池重新连接都重新解析，停止矿工后关闭临时通道。解析服务不可用时明确报错，不回退到此次出现异常的系统解析。其他矿池仍使用原配置。

## 网页配对排查

线上网页已提供「检查助手连接」。该按钮只检查本机助手是否可访问，不启动矿工、不读取账户数据，也不完成配对。成功后用本机最新配对码点击「配对当前电脑」。连接错误会保留显示，不再被两秒刷新覆盖。浏览器请求明确的 127.0.0.1 地址，由浏览器自行判定本机地址空间；不附加可能与其判定冲突的地址空间选项。

## 退出挖矿与删除数据

网页「连接当前电脑」提供「退出挖矿 / 清除本机数据」入口，打开本机助手的退出挖矿区。

- **清除本机数据**：输入「清除」确认后，先停止当前矿工，删除保存的矿池设置、只读 API 凭证、旧设备标识、全部网页配对、运行配置、日志和算力记录。助手恢复默认设置与新的设备配对信息，矿工保持停止。助手程序和登录启动项保留。该操作仅可从本机页面发起，远程网页即使已配对也不能直接执行。
- **彻底卸载助手**：在本机助手下载卸载文件；解压后 Mac 双击 `uninstall-mac.command`，Windows 双击 `uninstall-windows.cmd`，输入 DELETE 确认。仅删除本助手固定安装目录、其中的 Node/XMRig 与数据，以及本助手的登录启动项；只停止对应安装目录的进程。解压目录中临时手动运行的助手，请先停止终端再删除其文件夹。

删除本机数据或卸载均不会操作 unMineable 账户、余额、提现地址或其他设备。浏览器中的旧令牌清除后不能使用；旧页面发现配对失效时会自动移除本浏览器令牌。下载目录的安装包不属于已安装助手，可自行删除。

## 一键启动

下载并解压后，双击顶层「启动挖矿助手」。首次自动安装并打开本机助手页面；后续直接打开页面，助手未运行时启动它。已运行的助手及矿工不会被重复启动或停止。默认不自动挖矿。安装后桌面会生成本助手启动入口，完整卸载会一并删除本助手生成的桌面入口。底层程序放在「助手文件」中，无需逐个操作。Mac 首次打开若被系统拦截，需要用户按 Apple 官方步骤确认此文件的来源后单独放行，不能承诺绕过系统认证。Windows 仅提供 x64 包，尚未在 Windows 实机验证启动。
