工具介绍 / 常见问题

使用指南
让挖矿状态看得见，也让停止更简单

用一个网页，管理当前电脑的挖矿。

MASION 挖矿控制台通过本机助手运行 XMRig，提供启动、停止、线程设置、算力监控和日志查看。当前版本使用 CPU 运行 RandomX，并读取矿池账户的 LTC 收益。

CPU 挖矿 · RandomX本机运行 · 手动启动LTC 收益 · 只读同步
  1. 01
    你的电脑计算本机助手运行矿工，向矿池提交有效份额。
  2. 02
    矿池计算奖励unMineable 根据有效工作量记账、转换收益。
  3. 03
    账户获得 LTC网页读取金额；收款和提现在矿池后台设置。
网页和本机助手各有什么作用？

网页是操作面板，助手负责在电脑上执行。网页显示状态、配置和日志；本机助手启动、停止并监控 XMRig。每台电脑先安装、运行助手，再用配对码连接。所有操作都作用于当前已配对的电脑，挖矿消耗的是这台电脑的资源。

打开网址本身不会开始挖矿。需要在已连接的网页上点击“启动矿工”。

这个工具实际挖什么？为什么余额显示 LTC？

当前矿工使用 RandomX（rx/0），向 unMineable 的 RandomX 矿池提供 CPU 算力。矿池将挖矿奖励转换为你选择的结算币种。当前账户选择 100% LTC，因此余额以 LTC 显示。

这与直接运行莱特币的 Scrypt 算法不同。工具当前没有其他算法的切换入口。

支持哪些电脑？会使用显卡吗？

提供 Mac Apple 芯片、Mac Intel 和 Windows x64 助手下载。当前版本只使用 CPU，没有接入 M4 的 Apple GPU，也没有启用 NVIDIA 或 AMD 显卡挖矿。

装有 RTX 5090 的电脑运行当前助手时，使用的仍是那台电脑的 CPU。显卡挖矿需要另外接入兼容的矿工程序和算法。

线程越多越快吗？怎样修改线程数？

默认 4 个挖矿线程，给日常使用留出余量。当前可设置的上限取电脑 CPU 核心数与 10 中的较小值。不同核心的速度、缓存和内存都会影响结果，线程更多不一定让总算力更高。

先停止矿工 → 调整线程数 → 保存配置 → 再启动。以启动日志里的“READY threads”确认实际线程数，并比较稳定后的平均算力。活动监视器显示的进程线程还包含网络、监控等辅助线程。

有效份额是什么？每个份额能得到多少 LTC？

有效份额（accepted）是矿池接受的一次有效工作证明，不是固定数量的 LTC，也不是挖出一个完整区块。份额难度、矿池奖励和币种兑换价格会变化，不能用份额数直接换算金额。

份额和拒绝数显示本次矿工运行情况；实际 LTC 金额以矿池记账和账户同步为准。

“已挖得 LTC”和账户余额有什么区别？

“已挖得 LTC”显示账户中尚未提现的挖矿所得；“LTC 账户”显示账户总余额，可能包含推荐奖励。金额来自整个 unMineable 账户，可能汇总多台电脑，不等于当前电脑单独的收益。

连接只读 API 后每 60 秒同步一次。未连接时显示“—”；同步失败时会提示，并标明旧数据的时间。金额不会随每个份额即时增加，矿池记账也需要时间。

前往连接 LTC 收益 →
能换成其他结算币种吗？

unMineable 支持多种结算币种，但当前控制台的收益显示只接入了 LTC。换币需要在矿池后台配置结算分配、收款地址与网络，同时调整控制台的金额显示。只改矿池用户名不会自动切换结算币种。

查看官方支持的结算币种 ↗
怎样把 LTC 充值到欧易？网页会自动提现吗？

在欧易获取 LTC 充值地址和网络，然后在 unMineable 后台单独保存、验证地址，并核对双方当前的最低金额与网络要求。矿池用户名是账户别名和矿工名，不是收款地址。

本工具只读取账户数据，不执行提现、卖币，也不会替你开启自动提现。提现门槛、进度及自动提现设置以矿池官方后台为准。

关闭网页、关机或连接失败后，还会挖矿吗？

关闭网页或取消浏览器配对不会停止正在运行的矿工。要停止，请点击网页“停止”，或打开本机助手点击停止。电脑关机或助手服务退出后，矿工不能继续运行；重新启动助手不会自动开始挖矿。

“未连接”只表示网页暂时联系不上助手，不代表矿工一定停止。先确认助手已启动，并允许浏览器访问本地网络；配对码过期时，使用本机页面的新配对码重新配对。

不想挖了，怎样清除数据或完整卸载？

在本机助手的“清除这台电脑的挖矿数据”中，按提示确认，可停止矿工并删除本机挖矿设置、API 凭证、设备配对和运行记录；助手本身与登录启动项仍保留。

需要连助手一起移除时，使用本机助手里的“彻底卸载助手”，按说明运行对应卸载程序。这两种操作都不会删除矿池账户和已获得的 LTC。卸载后可自行删除下载包和解压目录。
